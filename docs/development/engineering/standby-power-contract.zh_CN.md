# 待机功耗契约

## 职责与接口

音频任务独占运行期间 codec 的打开、读写、暂停和关闭。`bsp_audio_pause(void)` 停止两个 I2S 通道并释放音频睡眠锁，同时保留 ES8311 偏置和滤波器状态。`bsp_audio_set_format()` 在同格式下恢复新的 DMA，不重置 codec，首次 16-bit 单声道读取先读走一个不完整的 I2S 槽采样（16 kHz 下为 62.5 微秒），再返回完整请求帧。`bsp_audio_suspend()` 用于彻底关闭或格式切换。生命周期调用幂等、串行执行且不进入按键回调。暂停部分失败时，在所有活动通道停止前保留睡眠锁；恢复失败允许重试。保留模拟供电带来的静态电流仍须测量。

`bsp_lvgl_set_paused(bool paused)` 在持有 LVGL 锁时调用，熄屏暂停刷新、动画定时器和 port tick，恢复时补回流逝时间。必须保持 LVGL 定时器处理器启用：LVGL 9.5 的禁用处理器返回 1 ms 延迟，会造成轮询。电量更新不能唤醒显示。

UI 生产者更新受保护的状态快照并通知工作任务；初始化后只有该任务修改 LVGL 对象和背光。重复且相同的主机状态不重置空闲超时。亮度保持 65/38/18/0%，3 秒变暗、20 秒熄屏；录音和处理维持原有亮屏行为。

## 兼容性与失败策略

BLE V1、ADPCM 帧、16 kHz 录音、开机音让位、ADC 键映射、分区和 Recovery 保持不变。任务通知配合状态检查，音频暂停过程中到达的事件不得丢失。音频启动失败报告错误并回到闲置。LVGL 暂停可恢复且检查错误。重复切换须保持 PM 锁成对。

USB 待机轮询（`main/usb_standby.c`）在原生 USB Serial/JTAG 总线活跃期间持有禁止轻睡眠锁和 80 MHz APB 频率下限，并以 5 秒释放宽限容忍主机侧短暂扰动；拔线或总线长时间挂起后恢复电池待机。音频暂停失败时重试或报错并回到闲置，不得中止设备。主机挂起及重插行为须独立完成硬件验收。
