# 待机功耗决策

## 决策

将仅关闭背光的待机策略替换为闲置 I2S 暂停、事件驱动 UI 和 ESP-IDF 自动轻睡眠及 BLE Modem-sleep。没有既有编号 ADR；本决策仅取代硬件指南中的背光待机行为。BLE V1、亮度、空闲超时、三键及 Recovery 契约保持有效。

## 替代方案与风险

深睡眠会断开 BLE 并改变唤醒行为，本次不采用。ADC 电阻分压按键的 GPIO 唤醒需要实测，本次保留 20 ms 扫描，去抖改为一个扫描周期，尽量接近原来的 10 ms 确认时间。工作时保留 160 MHz，闲置时使用 40 MHz；BLE 休眠使用主晶振，不假定存在外部 32 kHz 晶振。

实测板卡在 ES8311 完全关闭再打开后，会在每次录音开头重现削波瞬态。闲置期间保留 codec 偏置及滤波器状态，仅停止 I2S/DMA，避免重置 ADC，也避免以稳定等待为由丢弃每次录音开头。重启后的首次 16-bit 单声道读取先读走一个不完整 I2S 槽采样（16 kHz 下为 62.5 微秒），避免污染 ADPCM 初始值。音频禁止轻睡眠锁只在 I2S 活跃期间持有，背光亮起时保留背光锁。此方案保留 codec 模拟静态电流，不改变 LCD 控制器供电或 BLE 连接参数。净节电幅度、电池轻睡眠后的音频恢复及唤醒延迟仍须真机测量。
