# 待机功耗契约

## 职责与接口

音频任务是运行期间 codec 打开、读写及暂停的唯一所有者。`bsp_audio_suspend(void)` 关闭流并释放睡眠锁，重复调用无副作用。`bsp_audio_set_format()` 对暂停状态下的同格式也必须重新打开。失败清理停止两个 I2S 通道并支持重试。按键回调不执行 codec 操作。

`bsp_lvgl_set_paused(bool paused)` 在持有 LVGL 锁时调用，熄屏暂停刷新、动画定时器和 port tick，恢复时补回流逝时间。必须保持 LVGL 定时器处理器启用：LVGL 9.5 的禁用处理器返回 1 ms 延迟，会造成轮询。电量更新不能唤醒显示。

UI 生产者更新受保护的状态快照并通知工作任务；初始化后只有该任务修改 LVGL 对象和背光。重复且相同的主机状态不重置空闲超时。亮度保持 65/38/18/0%，3 秒变暗、20 秒熄屏；录音和处理维持原有亮屏行为。

## 兼容性与失败策略

BLE V1、ADPCM 帧、16 kHz 录音、开机音让位、ADC 键映射、分区和 Recovery 保持不变。任务通知配合状态检查，音频关闭过程中到达的事件不得丢失。音频启动失败报告错误并回到闲置。LVGL 暂停可恢复且检查错误。重复切换须保持 PM 锁成对。

USB 待机轮询（`main/usb_standby.c`）在原生 USB Serial/JTAG 总线活跃期间持有禁止轻睡眠锁和 80 MHz APB 频率下限，并以 5 秒释放宽限容忍主机侧短暂扰动；拔线或总线长时间挂起后恢复电池待机。音频关闭失败时重试或报错并回到闲置，不得中止设备。仅在真实主机挂起后丢失的串口需要重新插拔。
